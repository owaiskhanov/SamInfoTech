# Sam Infosystems — Website

A complete re-architecture of **saminfosystems.com** (Sam Infosystems Pvt Ltd, Mumbai).
Same information architecture and every piece of copy from the original site, rebuilt as a
fast, accessible, SEO-complete Next.js application with original artwork.

---

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build (33 prerendered routes)
npm start
npm run assets       # regenerate images, favicons & the social card from assets-src/
```

---

## What was extracted from the original site

Every page, every service, every string of body copy, all contact details and the full
navigation were read from the live WordPress site and preserved verbatim in
[`src/lib/site.ts`](src/lib/site.ts) — the single source of truth used by the pages, sitemaps,
structured data and the OG-image generator.

## Metadata & SEO

- Per-route `title` / `description` tuned to ≤60 and ≤158 characters (no SERP truncation),
  canonical URLs, Open Graph and Twitter `summary_large_image` on **every** route.
- **JSON-LD**: `Organization`, `WebSite`, `ItemList` (site navigation), `LocalBusiness`
  (contact page) and a `Service` node on each of the 22 detail pages.
- `sitemap.xml` and `robots.txt` are generated from the same data source (`src/app/sitemap.ts`,
  `src/app/robots.ts`), so a new offering appears everywhere automatically.
- Semantic landmarks, one `<h1>` per page, breadcrumbs, visible focus rings, skip link,
  `prefers-reduced-motion` support and a no-JavaScript fallback for scroll reveals.

## Icons & social card

Everything is generated by `npm run assets` (`scripts/build-assets.mjs`):

| Asset | Purpose |
| --- | --- |
| `favicon.ico` | 16/32/48 px frames, hand-written ICO container |
| `icon.svg`, `favicon-32x32.png`, `favicon-96x96.png` | Modern + legacy favicons |
| `apple-touch-icon.png` (180²) | iOS home screen |
| `android-chrome-192/512` + `maskable-512` | PWA / Android, with safe-zone variant |
| `safari-pinned-tab.svg` | Monochrome mask for Safari pinned tabs |
| `manifest.webmanifest`, `browserconfig.xml` | Install + Windows tiles metadata |
| `social-share.jpg` (1200×630) | Open Graph / Twitter card — the artwork the site shares |
| `opengraph-image.png` (1200×630) | Lossless twin of the share card |

The monogram is original SVG: a hexagonal shield whose negative space reads as an **S**,
drawn by hand in [`src/components/Logo.tsx`](src/components/Logo.tsx) and again in the icon
build script. **No third-party vendor logo files are bundled** — product tiles use original
geometric marks, which keeps the site trademark-clean and lightweight.

## Stack

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript · Sora + Manrope
(self-hosted variable fonts, zero external font requests) · satori + resvg + sharp for
asset generation.

## Design system

Dark "deep navy → cyan" palette defined once as Tailwind v4 theme tokens
(`src/app/globals.css`): `ink` surfaces, `brand`/`azure` accents, `mist` text tiers, plus
custom utilities (`container-x`, `text-gradient`, `eyebrow`, `glass`, `card-hover`).
All effects are pure CSS — no animation libraries.
