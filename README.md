# Sam Infosystems — Website

A complete re-architecture of **saminfosystems.com** (Sam Infosystems Pvt Ltd, Mumbai).
Same information architecture and every piece of copy from the original site, rebuilt as a
fast, accessible, SEO-complete Next.js application with original artwork.

---

## Quick start

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build (33 prerendered routes)
npm start
npm run assets       # regenerate images, favicons & the social card from assets-src/
```

---

## What was extracted from the original site

Every page, every service, every string of body copy, all contact details and the full
navigation were read from the live WordPress site and preserved verbatim in
[`src/lib/site.ts`](src/lib/site.ts) — the single source of truth used by the pages, sitemaps,
structured data and the OG-image generator.

## Metadata & SEO

- Per-route `title` / `description` tuned to ≤60 and ≤158 characters (no SERP truncation),
  canonical URLs, Open Graph and Twitter `summary_large_image` on **every** route.
- **JSON-LD**: `Organization`, `WebSite`, `ItemList` (site navigation), `LocalBusiness`
  (contact page) and a `Service` node on each of the 22 detail pages.
- `sitemap.xml` and `robots.txt` are generated from the same data source (`src/app/sitemap.ts`,
  `src/app/robots.ts`), so a new offering appears everywhere automatically.
- Semantic landmarks, one `<h1>` per page, breadcrumbs, visible focus rings, skip link,
  `prefers-reduced-motion` support and a no-JavaScript fallback for scroll reveals.

## Brand logos

The 11 products are shown with their **real marks**, not stand-ins:

- Official paths come from **Simple Icons** (CC0) for Azure, AWS, Microsoft,
  Adobe Creative Cloud, CorelDRAW, Fortinet and AutoCAD — vendored into
  `src/lib/brand-marks.ts` so the runtime carries no extra dependency.
- **Google Workspace, Microsoft 365, Sophos, Tally ERP.9 and HR Solutions** are
  hand-drawn in the same file, because no CC0 official vector exists for them.
- Each mark renders in its own brand colour. Two colours are swapped for
  legibility on our dark surfaces (AWS navy → `#FF9900`, CorelDRAW black →
  near-white); everything else is verbatim brand colour.

## Icons & social card

Everything is generated by `npm run assets` (`scripts/build-assets.mjs`):

| Asset | Purpose |
| --- | --- |
| `favicon.ico` | 16/32/48 px frames, hand-written ICO container |
| `icon.svg`, `favicon-32x32.png`, `favicon-96x96.png` | Modern + legacy favicons |
| `apple-touch-icon.png` (180²) | iOS home screen |
| `android-chrome-192/512` + `maskable-512` | PWA / Android, with safe-zone variant |
| `safari-pinned-tab.svg` | Monochrome mask for Safari pinned tabs |
| `manifest.webmanifest`, `browserconfig.xml` | Install + Windows tiles metadata |
| `social-share.jpg` (1200×630) | Open Graph / Twitter card — the artwork the site shares |
| `opengraph-image.png` (1200×630) | Lossless twin of the share card |

The Sam Infosystems monogram is original SVG: a flat hexagonal shell with a thin **S**
stroked through it, drawn in [`src/components/Logo.tsx`](src/components/Logo.tsx) and again
in the icon build script. It is single-colour `currentColor`, so it inherits the accent in
any context.

## Stack

Next.js 15 (App Router) · React 19 · Tailwind CSS v4 · TypeScript · Inter + Inter Tight
(self-hosted variable fonts, zero external font requests) · satori + resvg + sharp for
asset generation.

## Design system

**Flat, no gradients.** Depth comes only from hairline borders (`--color-line`), flat
surface tints (`ink-950 → ink-600`) and generous whitespace — there is not a single
`linear-gradient` or glow in the shipped CSS.

- **Type**: Inter Tight for display, Inter for body, both at `font-weight: 300` with
  tight tracking — thin and quiet, with a hierarchy carried by size and space rather
  than weight or colour.
- **Colour**: one accent (`brand-300 #6FDCEA`) plus four `mist` text tiers. Brand
  colours appear only inside the product logos, which keeps the page calm.
- **Motion**: every section enters with a **blur-in** (14px → 0) plus a small lift,
  driven by an `IntersectionObserver` (`<Reveal>`) and CSS `@keyframes`. Grids stagger
  at 50ms intervals; the hero replays its sequence on each slide. Fully disabled under
  `prefers-reduced-motion`, and content is visible without JavaScript.
- **Responsive**: single-column from 320px, two columns at 420px, three at `lg`, with
  `grid-cols-*` breakpoints on every grid and no fixed pixel widths or `nowrap` text.
